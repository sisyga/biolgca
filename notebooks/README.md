# BioLGCA notebooks

## Maintained tutorials

The maintained, tested curriculum lives in
[`docs/source/tutorials/`](../docs/source/tutorials/). Start with
[`01_fundamentals.ipynb`](../docs/source/tutorials/01_fundamentals.ipynb) and
continue in numerical order. These notebooks use the current `ModelSpec` API,
show every interaction pipeline in visible cells, and execute during the
strict documentation build.

## Historical notebooks

[`legacy/`](legacy/) contains `BioLGCA.ipynb` and
`Evolutionary LGCA.ipynb`. They are preserved as historical records of the
older factory-based teaching material. They contain saved outputs, use older
Jupyter/Matplotlib conventions, and are not executed in CI. Do not use them as
the starting point for a new simulation.

## Research-project example

[`research_projects/SRP_Notebook.ipynb`](research_projects/SRP_Notebook.ipynb)
is a project-specific historical notebook about pushed and pulled invasion
fronts. It illustrates the scope of a student research project but is not a
general BioLGCA tutorial and is not maintained or executed in CI.
